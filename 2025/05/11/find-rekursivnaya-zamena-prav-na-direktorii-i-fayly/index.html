Find рекурсивная замена прав на директории и файлы

2025-05-11
  • find
  • linux

Как использовать find с -exec для изменения прав доступа к файлам и директориям

В Linux часто возникает задача массового изменения прав доступа к файлам и папкам. Для этого удобно использовать команду find вместе с опцией -exec. В этой статье подробно разберём, как работает конструкция с {} и \;, и приведём примеры для изменения прав доступа к директориям и файлам.

Основы команды find -exec

Команда find используется для поиска файлов и директорий по заданным условиям. Опция -exec позволяет выполнить произвольную команду над каждым найденным элементом.

Синтаксис:

  • <путь> — директория, в которой происходит поиск.
  • <условия> — фильтры (например, -type d для директорий, -type f для файлов).
  • <команда> — команда, которую нужно выполнить.
  • {} — плейсхолдер, который заменяется на текущий найденный файл или директорию.
  • \; — обозначает конец команды -exec. Обязательно экранировать ;, чтобы оболочка не интерпретировала его.

Как работает конструкция {} и \;

Рассмотрим пример:

Что происходит:

  1. find находит первую директорию, например dir1.
  2. В команде -exec подставляет {} на место dir1 и выполняет: chmod 755 dir1
  3. Затем find находит следующую директорию, например dir2.
  4. Опять подставляет {} на место dir2 и выполняет: chmod 755 dir2
  5. И так далее для всех найденных директорий (dir3, dir4 и т.д.).

Таким образом, команда chmod 755 выполняется отдельно для каждого найденного элемента.

Пример 1: Изменить права доступа для директорий

  • -type d — ищет только директории.

  • Для каждой найденной директории выполняет chmod 755, что означает:

    • Владелец: чтение, запись, выполнение
    • Группа: чтение, выполнение
    • Остальные: чтение, выполнение

Пример 2: Изменить права доступа для файлов

  • -type f — ищет только файлы.

  • Для каждого файла выполняет chmod 644, что означает:

    • Владелец: чтение, запись
    • Группа: чтение
    • Остальные: чтение

Почему важно использовать {} и \;

  • {} — обязательно, чтобы find знал, куда подставлять имя текущего найденного файла или директории.
  • \; — служит для указания конца команды -exec. Экранирование обратным слэшем необходимо, чтобы оболочка не воспринимала ; как окончание команды.

Альтернативы: + вместо \;

В этом случае find передаёт несколько найденных файлов за один вызов команды, что может быть эффективнее. Но в некоторых случаях нужно именно выполнять команду отдельно для каждого элемента — тогда используется \;.

Итог

  • Команда find с -exec позволяет выполнять операции над каждым найденным файлом или директорией.
  • {} — это шаблон, который заменяется именем текущего найденного объекта.
  • \; — обозначает конец команды.
